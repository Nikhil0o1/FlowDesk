## Commands

```bash
npm test                  # all Vitest suites
npm run test:unit
npm run test:integration
npm run test:smoke
npm run test:security     # VAPT vitest checks only
npm run security:local    # audit + verify:deps + verify:third-party + test:security
npm run security:scan     # full local gate (Git Bash; Snyk/Gitleaks/TruffleHog if installed)
npm run test:coverage
npm run sync:coverage-summary   # refresh tests/coverage-summary.json
npm run test:e2e          # Playwright (local only; needs API + Postgres)
```
